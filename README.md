# Amazon India Revenue Insights

## Project Overview

Amazon India Revenue Insights is a business intelligence project designed to analyze sales performance, revenue trends, profitability, and customer purchasing behavior. The project transforms raw sales data into meaningful insights using Python, SQL, and Power BI.

---

## Objectives

- Analyze revenue performance across products and categories
- Identify top-performing products and regions
- Evaluate business performance through data analysis
- Discover sales and profit trends
- Support data-driven decision making

---

## Tools & Technologies

- Python
- SQL
- Power BI
- Excel
- Pandas
- NumPy

---

## Key Performance Indicators

- Total Revenue
- Total Profit
- Order Volume
- Top Products
- Category Performance
- Monthly Sales Trends

## Dashboard Features

- Interactive KPI Cards

- Product Performance Insights
- Profitability Tracking

## Business Insights

This project helps stakeholders understand sales performance, identify growth opportunities, optimize product strategy, and improve overall business decision-making through data visualization and analytics.
